Stop retyping heading styles by hand.

K-Doc Header finds headings formatted manually in a Word document and reapplies the correct named heading style — so Navigation Pane, auto-TOC, and document outlines just work.

⬇ Download for Windows Installer · v1.1.0 View on GitHub
Why it exists

Manuscripts drift from their template

Authors resize and bold text by hand instead of using Word's Heading styles. The document looks right — until Navigation Pane, TOC generation, or an export pipeline needs the real structure.

⚡

Automatic detection

Matches each paragraph's font, size, and weight against a learned signature map — no manual tagging, no regex rules to write.

🎯

Drift-tolerant

Handles imprecise hand-formatting (±1.5pt size drift, missing bold) without misclassifying heading levels.

🛡️

Non-destructive

Your original file is never modified — output is saved as a new _styled.docx alongside it.

How it works

Three steps, no configuration

  1. 1

    Drop in a .docx

    Drag a manuscript onto the app window, or choose files from the file picker.

  2. 2

    It detects heading formatting

    Each paragraph's font, size, and boldness are compared against the learned style signatures.

  3. 3

    Get a properly-styled copy

    Headings are retagged with real Word styles — Navigation Pane and auto-TOC work immediately.
